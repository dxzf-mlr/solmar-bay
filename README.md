Solmar Bay is an original 3D open-world crime game: a golden-hour seaside city
to explore on foot and by car. Dana Cruz drives for a living; Mama Rosa has
seven story jobs for her, from courier runs and a repo job to a harbor deal and
one last heist. Steal cars, outrun the police across a 0–5 star wanted level,
fight back with fists and a pistol, and get paid. The city has traffic and
pedestrians, a beach, a pier, a ring highway, a HUD with a live minimap, synth
sound (engine, sirens, radio), and saves that survive between sessions.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network:
the game is plain static files under `game/`, with three.js vendored at
`game/vendor/three.min.js`.
